# 🎬 Movie Search UI

A simple and responsive movie search web application built using HTML, CSS, and JavaScript. Users can search for movies and view results in a clean UI.

---

## 🚀 Live Demo

👉 https://pratik-code7.github.io/Movie-Search-UI/

---

## 📌 Features

- 🔍 Movie search functionality
- 🎥 Dynamic movie result display
- 📱 Fully responsive design
- ⚡ Fast and lightweight UI
- 🎨 Clean and modern layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Movie API (OMDb / TMDB)
